# 內存掃描指南

CotwMod 內建掃描器，用法與 Cheat Engine 類似。只在單人模式使用；只讀寫遊戲進程內存，不改任何遊戲檔案。

## 基本流程

1. 啟動遊戲（無邊框視窗）進入保護區，再開 CotwMod。頂部顯示「● 游戏已连接」。若一直未連接，以系統管理員身分執行。
2. 「內存掃描」頁：選類型、方式，按「首次扫描」；改變遊戲中的狀態後選比較方式按「再次扫描」，直到結果只剩幾個。
3. 點選結果 → 選「綁定為」欄位 → 先「绑定（绝对地址）」測試，右側「已绑定的字段」會即時顯示數值，確認它跟著遊戲變化。
4. 確認無誤後按「指针扫描」，在結果中點最上面一條「绑定」。絕對地址在遊戲重啟後失效，指針鏈則長期有效（遊戲大版本更新後可能需要重找）。

「未知初始值」掃描會把整個遊戲內存快照到臨時資料夾，第一次可能需要數十秒和數 GB 磁碟空間；之後的掃描會快很多，結果少於 500 萬時自動轉為列表。

## 各欄位怎麼找

| 欄位 | 類型 | 方法 | 綁定後調整 |
|---|---|---|---|
| 手持武器 ID | 4 Bytes | 未知初始值 → 換武器「已改變」→ 不換「未改變」，重複 3–4 輪；換回原武器值應回到原數 | 在「手持武器識別」把每個 ID 對應到武器 |
| 箭矢 ID | 4 Bytes | 同上，切換箭矢 | 同上 |
| 瞄準距離 | Float | 用測距儀看物體，「精確值」填顯示距離，容差 0.5；換物體再掃 | — |
| 鏡頭俯仰 | Float | 抬頭「增大」、低頭「減小」 | 若顯示弧度（約 ±1.5），縮放填 57.29578 |
| 鏡頭朝向 | Float | 原地順時針轉「增大」/逆時針「減小」，與畫面羅盤對照 | 方向相反：縮放 -1；有固定差：用「加」 |
| 風來向 | Float | 風向改變時「已改變」，穩定時「未改變」 | 與 HUD 風向對照，同上調整 |
| 風速 | Float | 風力等級變大「增大」，變小「減小」 | — |
| 鏡頭 FOV | Float | 開鏡「減小」、收鏡「增大」 | 綁定後放大倍率自動處理 |
| 獵物可視距離 | Float | 見下 | 可綁定多個 |

### 獵物可視距離（400–800 m）

這個數值沒有 HUD 可以對照，需要試：

- 若遊戲畫質選項會影響動物顯示距離：在不同預設之間切換，配合「已改變 / 未改變」。
- 或用「範圍」掃描（例如 100–1000）縮小後，逐個用「写入一次」測試，觀察遠處動物是否出現。
- 找到後綁定（可多個，例如不同 LOD 層級），用滑桿設定 400–800 m，勾選「持续锁定」防止遊戲重設。

寫入錯誤地址可能導致遊戲崩潰：測試前先存檔。距離越大 CPU 負擔越重。

## 診斷

`CotwMod.exe --selftest` 會連接遊戲，列出主模組位址和可讀內存區域，結果寫入 `cotwmod_selftest.txt`。附帶一個當前顯示的 Float 數值（例如 `--selftest 123.5`）時，會額外做一次掃描和指針掃描。
