# 彈道校準指南

每個 **武器 + 箭矢** 組合各校準一次（例如 Hawk Edge CB-70 + 420gr）。校準結果存在 `config/calibrated.json`，會覆蓋 `weapons.json` 的估計值。

## 0. 先校準螢幕比例（像素 ↔ 角度）

落點需要從角度換算成螢幕像素，這取決於解析度、FOV 設定和瞄準時的放大。

1. `config/settings.json` → `screen`：填入遊戲解析度和遊戲內 FOV 設定值。
2. 驗證：開 `cotwmod aim`，在靶場用**遊戲的歸零距離**射靶（例如歸零 40 m 就站在 40 m 處）。箭應落在中央小十字上。若有固定偏差（例如瞄具基準點不在螢幕正中），把偏差像素寫進 `aim_reference_px`。
3. 若之後擬合出的初速明顯不合理（例如高於 150 m/s 或低於 30 m/s），通常是 FOV 換算不對：試著切換 `fov_is_horizontal`，或直接設定 `px_per_mrad_override`。

## 1. 收集射擊資料

建議地點：Hirschfelden 的靶場，或任何平坦、能用測距儀量距離的地方。**選無風或微風的時候先射**，最後再補幾發側風。

1. `cotwmod aim`，用 Alt+F7/F8/F9 選好武器、箭矢、歸零（必須與遊戲內一致）。
2. 輸入目標距離（Alt+PgUp/PgDn，或記憶體模式自動讀取）。
3. 中央十字對準靶心，**屏息、站姿**射擊，減少隨機散佈。
4. Alt+F11 進入校準模式，出現紅框。用 Alt+方向鍵 把紅框移到箭實際插入的位置。
5. Alt+Insert 記錄。紅框位置、距離、歸零、風都存入 `config/calibration_shots.json`。
6. 再按 Alt+F11 退出校準模式，換下一個距離。

建議距離：10、20、30、40、50、60、70 m，每個距離 2–3 發（取平均可消除遊戲的隨機散佈）。至少要有 3 個不同距離才會擬合阻力；有記錄到風的射擊時才會擬合風偏係數。

## 2. 擬合

```bat
cotwmod calibrate --dry-run     # 先看結果
cotwmod calibrate               # 寫入 calibrated.json
```

輸出的 `rms` 是模型與實測的平均偏差（mrad）。1 mrad 在 50 m 處 = 5 cm。
- rms < 0.3：很好
- rms > 0.5：檢查是否選錯歸零/箭矢、距離輸入錯誤，或射擊次數太少

## 3. 驗證

`cotwmod table -w <武器> -a <箭> -z <歸零>` 會列出各距離的下墜。可以與遊戲內瞄具針的距離對照（例如多針瞄具每根針對應的距離），應該吻合。

## 參數說明

| 參數 | 意義 |
|---|---|
| `muzzle_velocity` | 出弓速度 m/s |
| `drag_k` | 阻力係數 (1/m)，越大越快減速 |
| `wind_factor` | 遊戲風力對箭的影響倍數 |
| `sight_height` | 瞄具在箭上方的高度 (m)，影響近距離 |
